# Project Content

## Title

AI-Powered Open Finance Data Platform

## One-line summary

An open-finance portfolio project that ingests mock account and transaction data, normalizes it into a common financial data model, and generates explainable financial insights through an agentic workflow.

## Projects page card

AI-Powered Open Finance Data Platform — A Plaid-aligned product/data platform that turns fragmented financial account and transaction records into a normalized financial data model, then uses an explainable AI workflow to surface cash-flow, recurring payment, subscription, affordability, and risk/opportunity signals.

## Project description intro

This project explores the product foundation behind open finance: financial data is only useful when it can be connected, normalized, interpreted, and reused across applications. The platform ingests mock Plaid-style institutions, accounts, balances, and transactions, maps them into a Common Financial Data Model, and runs an agentic analysis workflow that produces financial health signals and recommendations.

## Why this project matters

The goal is not to build a consumer budgeting app. The goal is to show how a developer-platform-oriented financial data layer can support downstream product experiences: underwriting, cash-flow analysis, subscription detection, affordability, financial health, and operational decision support.

## PM positioning

This project connects prior experience in common data models, data platforms, and workflow orchestration with a fintech/open-finance use case. It demonstrates the ability to reason across source data, canonical models, user-facing workflows, and AI-assisted product experiences.
